# DraftStack Website

Official website for **DraftStack** — a modern software engineering startup crafting bespoke web applications, internal operational systems, and digital tools for forward-thinking companies and professional practices.

## Design

Built with a "Softly" design system:
- **Palette**: Warm linen background (`#FDFCF8`), Sage (`#E8EFE8`), Lavender (`#EFEDF4`), Coral/Peach accent (`#FFB7B2`), and soft stone text (`#292524`).
- **Typography**: Clean, rounded Google Font `Outfit` paired with expressive handwritten cursive `Reenie Beanie`.
- **Analog Texture**: 35% opacity SVG fractal noise grain overlay (`feTurbulence`) and fluid ambient floating background blobs.
- **Interactive Features**: Floating glassmorphic pill navbar, horizontal drag-and-scroll scenario carousel, three-mockup cascading interactive app preview with tabbed UI, diary-style partner testimonials, and interactive FAQ accordion.

## Structure

Static HTML5, CSS3, and modern vanilla JavaScript — zero build steps or heavy dependencies.
Open `index.html` in any browser or serve statically.
